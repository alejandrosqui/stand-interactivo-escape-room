# User Story Mapping

## Producto

Aplicación web móvil para un stand con desafíos físicos y digitales. Los usuarios principales son el participante del evento y el administrador del stand. La experiencia debe completarse en 3 a 7 minutos.

## Recorrido del participante

**Descubrir → iniciar → comprender → resolver → finalizar → recibir recompensa**

### MVP

- Descubrir: VIS01, VIS04.
- Iniciar: VIS02, VIS03.
- Comprender: ESC01, ESC02.
- Resolver: ESC03–ESC08.
- Finalizar: ESC11, ESC12.
- Recompensa: GAM01, GAM02.

### Versión 1.1

VIS05, ESC09, ESC10, GAM03 y GAM04.

### Posterior

GAM05 y GAM06, además de inicio por NFC, misiones adaptativas y desafíos dinámicos.

## Recorrido del administrador

**Crear experiencia → configurar desafíos → vincular elementos → publicar → operar → analizar**

### MVP

- Crear: ADM01–ADM04.
- Configurar: ADM06–ADM10, ADM12, ADM13.
- Vincular: ADM14–ADM16.
- Publicar: ADM03, ADM18.
- Operar y registrar: DAT01–DAT05.

### Versión 1.1

ADM05, ADM11, ADM17, ADM19 y DAT06.

### Posterior

ADM20, biblioteca de experiencias, ramas adaptativas, IoT complejo y múltiples stands.

## Corte del MVP

Se incluye una experiencia activa, una secuencia lineal, acceso web por QR, pistas físicas identificadas, validación y feedback, temporizador, puntos, recompensa simple, panel esencial y registro de participación.

Quedan fuera del MVP NFC obligatorio, varias misiones simultáneas, ramas adaptativas, sensores IoT complejos, ranking público, redes sociales y analítica avanzada.
